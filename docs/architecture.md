# 设计说明

## 训练与服务边界

训练阶段负责数据切分、词表/特征空间拟合、召回模型构建、排序模型训练和指标产出。服务阶段只负责读取已训练对象、过滤用户历史、执行三路召回和排序，不重新读取公司数据。

## 召回融合

热度召回保证新用户有结果；ItemCF 从同一用户的历史正反馈扩展相似商品；矩阵分解召回学习用户和商品的隐向量；内容召回使用用户偏好品类、城市和商品质量分。`HybridRetriever` 将每一路的归一化排名按权重相加，并保留多个来源，方便解释和监控。

## 防止评估泄漏

测试集是每个用户按时间排序后的最后若干条正反馈，训练集包含更早的行为。推荐结果会过滤训练集中的正反馈，因此离线指标反映的是“根据过去行为预测未来行为”，而不是随机切分得到的偏乐观结果。
